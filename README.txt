Congreso y Senado — mapa editable (optimizado)

Deploy to Vercel:
1. Go to https://vercel.com/new
2. Import a Git repository containing this folder, or use Vercel CLI from this folder.
3. For a static site, no build command is required. Set the output directory to . (the folder containing index.html).
4. Deploy.

This is a static HTML app. It uses external CDN resources for the Inter font and SheetJS (Excel import/export), so those features require internet access. The core map and editing features run in the browser.
